# INK 目前能力與限制

## 已有工程能力

- HTML 畫布與編輯介面。
- Scene／Document 狀態。
- 基本輸入與筆畫鏈。
- 圖層、History、Undo／Redo 的既有架構。
- 保存、重播與 PNG 輸出鏈。
- AI Action Validator／Dispatcher。
- Vector Mask、Region、Recipe 與局部重編譯研究能力。
- 自然媒材表面、顏料量與非週期填色研究模組。

## 尚未完成驗收

- 專業手繪軟體共同功能是否齊全。
- 所有筆刷參數是否可由 UI 操作。
- 實體 MPP 觸控筆的壓力、傾斜與防掌觸。
- 完整油畫顏料狀態、畫布混色、厚塗與刮刀。
- 完整水彩水分、紙張、擴散、沉積與乾燥。
- 完整濾鏡、調整層與非破壞影像處理。
- AI 是否能利用 Action／Recipe 完成成熟原創油畫。

## 現階段判定

`INK 0.8.3` 是可持續開發的主程式基線，但不能標記為功能完整的專業手繪＋濾鏡＋筆刷工具。
