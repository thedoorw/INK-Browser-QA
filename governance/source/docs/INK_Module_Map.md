# INK 模組地圖

| 路徑 | 職責 |
|---|---|
| `src/ink.js` | 主程式組裝與服務安裝 |
| `src/core/` | 核心命令、狀態或共用服務 |
| `src/document/` | 文件、畫布與序列化 |
| `src/editor/` | 編輯器互動與工具 |
| `src/input/` | 滑鼠、觸控、觸控筆事件 |
| `src/stroke/` | 筆畫、筆刷與取樣 |
| `src/render/` | Canvas 繪製與合成 |
| `src/history/` | History、Undo、Redo、Transaction |
| `src/export/` | 圖像與文件輸出 |
| `src/spatial/` | 空間資料與命中判定 |
| `src/flora/action/` | AI Action Schema、Validator、Dispatcher |
| `src/flora/mask/` | Vector／Region Mask |
| `src/flora/recipe/` | Painting Recipe 編譯 |
| `src/flora/render/` | FLORA 繪畫策略與表面處理 |
| `tests/unit/` | 核心單元與回歸測試 |
| `tests/flora/` | FLORA 專項測試 |
| `scripts/` | Build、serve、fixture、ready check |
