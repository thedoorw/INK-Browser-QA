# INK 核心基線與版本

## 正式結論

目前主程式最後可確認版本為 `INK 0.8.3`。

最新整合工程包標記為 `WP-9A-R2.1 / 0.9A-R2.1`，但那是 FLORA 專案工作包版本，不是 INK 主程式語義版本。其視覺狀態為 `VISUAL_PREFLIGHT_FAIL`，不得升為視覺母版。

## 本基線的用途

- 作為後續 INK 手繪、筆刷、濾鏡功能稽核的唯一乾淨父基線。
- 作為 AI Action／Recipe 操作研究的程式基礎。
- 不包含 FLR-012 候選圖及大量 Runtime Evidence。
- 保留 FLORA 程式模組，僅因目前核心入口存在直接依賴。

## 不代表的事項

- 不代表油畫能力完整。
- 不代表水彩能力完整。
- 不代表所有手繪功能已經驗收。
- 不代表 AI 已能完成歐姬芙式原創油畫。
