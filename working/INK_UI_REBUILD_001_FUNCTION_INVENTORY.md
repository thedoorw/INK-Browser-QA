## Classification vocabulary

- `PRIMARY` — one canonical visible home
- `CONTEXTUAL` — appears only when current tool/selection makes it relevant
- `SHORTCUT` — secondary route to the same command
- `RESPONSIVE` — alternate placement only for smaller viewport
- `SPECIALIST` — advanced/diagnostic surface
- `REMOVE` — redundant, misleading, legacy, or dead
- `HOLD` — requires product-authority decision
