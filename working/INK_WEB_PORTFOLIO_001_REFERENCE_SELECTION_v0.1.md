## Selected target

The first reproduction target is the current public presentation system of The Minimalists.

Primary public evidence:
- https://www.theminimalists.com/
- https://www.theminimalists.com/contextual/
- https://www.theminimalists.com/page/2/
- https://www.theminimalists.com/resources/

## User direction

The desired portfolio is not primarily a full-screen project gallery.

It should behave more like:

```text
ongoing visual + written record
→ compact editorial page
→ individual work / entry
→ next / previous reading
→ continuing archive
```

The site must be able to look intentional and complete even when only a small number of works have been published. As new works, notes, processes and experiments are added, the site should grow naturally rather than reveal an obviously unfinished portfolio grid.

The reading experience should also support a book-like rhythm: one entry, work or chapter at a time.

## Why this reference

The current reference provides the required structural ideas:

- centered, non-full-width content;
- strong readable typography rather than full-screen spectacle;
- a continuing stream of entries;
- short title + summary + continuation pattern;
- individual article/detail pages;
- image and text living in one reading sequence;
- pagination through a long archive;
- previous/next continuity;
- secondary indexes/resources that remain within the same shell.


## Portfolio translation

The reproduction will preserve the presentation logic while replacing the content model.

Reference concept → portfolio concept:

```text
article stream      → works / notes / case entries
article title       → work title
excerpt             → short project statement
article body        → image + narrative + process
author/date/meta    → category / year / tools / status
previous/next       → sequential work reading
pagination          → growing portfolio archive
resources/index     → categories / index / selected collections
```

## First-reproduction scope

Include:
- restrained centered page shell;
- global navigation;
- intro / identity block;
- sequential homepage entry stream;
- representative entry-detail template;
- image + text reading rhythm;
- previous / next navigation;
- archive / pagination pattern;
- secondary index page;
- desktop / tablet / mobile responsive states;
- footer structure.

Exclude:
- original editorial copy;
- original copyrighted imagery;
- newsletter/email backend;
- paid products;
- ecommerce;
- WordPress/backend cloning;
- analytics.

## Reproduction method

```text
observe / capture
→ measure
→ structure decomposition
→ tokens
→ components
→ independent implementation
→ screenshot compare
→ responsive compare
→ correction
```

Do not copy the reference site's proprietary source code or content.

## Acceptance direction

The first reproduction is judged by whether CHAT / WEB DEV can recover and rebuild:

- page width and reading-column geometry;
- typography hierarchy;
- vertical rhythm;
- image/text relationship;
- navigation;
- entry-list rhythm;
- individual entry structure;
- sequential navigation;
- archive continuation;
- responsive transformation.

The long-term outcome is a reusable editorial portfolio shell, not a clone containing The Minimalists content.
